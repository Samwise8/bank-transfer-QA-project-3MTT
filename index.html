Bank Transfer QA Project

3MTT Software Testing Portfolio Project

Project Overview

This project demonstrates a structured Quality Assurance approach to testing the Bank Transfer feature of a simulated mobile banking application.

The project focuses on functional behaviour, transaction integrity, authentication, validation, error handling, duplicate transaction prevention and API testing.

Testing Results

40 Total Test Cases
31 Passed
7 Failed
2 Blocked
77.5% Pass Rate

Release Recommendation

NOT RECOMMENDED FOR PRODUCTION

The simulated application achieved a 77.5% pass rate, below the defined 95% exit criterion. Critical and High-severity transaction risks require remediation before release.
